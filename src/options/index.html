AI 接口

网页版模式（推荐）：分析时自动打开/复用 chat.deepseek.com 标签页，把提示词与截图填入输入框； 你按一次回车，回复自动读取（失败时可手动粘贴兜底），读取成功后自动关闭该标签页。
免费且响应快；依赖于 DeepSeek 页面结构，若注入失败请切回 API 模式。此模式忽略下方全部配置。

任意 OpenAI 兼容服务都能接入：预设含 DeepSeek／硅基流动／智谱／Kimi／通义／豆包／OpenAI／OpenRouter／本地 Ollama， 或选「自定义」填自己的地址与模型（One-API 等网关同理，API 地址填到 /v1 为止）。
阵容识别需要多模态（看图）模型，请优先选择带视觉能力的模型名。

高级

候选 = 送入 AI 的弹幕/评论条数（默认各 60）。调大召回更多，但提取精度与 API 成本会下降。

派遣关候选池会同时列出 MAA 作业与 B站实战视频。B站挖掘全程只用干员字典 + 别名表程序化提取 （标题 + 合集分P标题），不消耗 AI token；页数越多召回越高、耗时与触发B站风控的概率也略增（结果按 12 小时缓存）。 ⚠️ 同一显示码会在历次活动复刻中重复（如 VEC-SP12 在上一期也有），时间范围用来挡掉往期攻略； 该过滤在本地按发布时间执行（B站搜索接口的时间参数实测不生效）。

昵称纠错（本地积累）

分析时遇到干员字典无法识别的称呼（新黑话、新干员昵称）会自动记在这里。 填入正确的干员全名并采纳后，之后所有分析都会使用你的本地对照表。
积累的对照可「提交到社区」——并入共享对照表后，所有用户 24 小时内自动获得。
