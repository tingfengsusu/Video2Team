# 🎮 Video2Team

**把大佬的作业，改成你抄得动的作业**

> B站明日方舟挂机攻略视频 → AI 提取阵容 → 结合弹幕/评论区实战替代建议 + 我的干员 box → 输出一份我当前 box 能用的阵容。

🚧 **当前状态：设计阶段**（设计文档：[docs/design.md](docs/design.md)）

---

## 💡 解决什么问题

活动关挂机攻略的经典痛点：

1. 攻略阵容里有干员，我没有；
2. 「XX 可以用 YY 代替」的建议散落在几百条弹幕/评论里；
3. 一个个记、一个个核对、一个个试——太累。

Video2Team 把这三步压缩成一次输入：**丢一个视频链接 + 我的练度表，直接得到我抄得动的阵容**，每个替换位都标注来源（原阵容 / 弹幕建议 / AI 推断）和风险等级。

## 🔄 设计范式

本项目与 [Video2Shop](https://github.com/tingfengsusu/Video2Shop) 是同一范式的领域迁移：**视频 → 清单 → 对比持有 → 补齐方案**（配方→京东加购 ⟶ 阵容→替补填坑），约 60-70% 代码可复用。

```
① 阵容提取        ② 实战替代挖掘           ③ 匹配推荐
简介/置顶评论  →   弹幕XML/评论API     →    我有→保留
抽帧+OCR兜底      正则粗筛+LLM精筛          没有→实战映射命中→采用
                  干员名字典校验            无解→LLM推断(v1)
                                    →  输出：阵容+来源+风险标注
```

## 📌 核心设计决策

- **分析单元 = 单个视频**：攻略合集 = 一关一视频的系列，弹幕/评论天然按关卡隔离，无需路由；
- **box 导入**：v1 用[一图流](https://ark.yituliu.cn/survey/operators)导出的 Excel，v2 上森空岛扫码登录，Excel 永久兜底；
- **替代关系可靠度**：实战验证（弹幕/评论）> LLM 结合关卡机制推断 > 属性匹配（不做）；干员知识库只做名字典防幻觉 + 属性上下文，**不参与推荐**；
- **风险分级**：关键位替换一律高风险标注，提示回评论区验证——推荐翻车的容错远低于买错酱油。

## 📂 目录结构

```
Video2Team/
├── docs/design.md              # 设计文档（管道/数据模型/版本规划/风险）
├── src/
│   ├── models.py               # 核心数据模型（Roster/Substitution/Box/RecommendedSlot）
│   ├── pipeline.py             # 主管道编排
│   ├── roster_extractor.py     # ① 阵容提取
│   ├── comment_miner.py        # ② 实战替代挖掘（弹幕/评论）
│   ├── box_importer.py         # box 导入（Excel / 森空岛扫码）
│   ├── operator_db.py          # 干员名字典 + 属性上下文
│   ├── recommender.py          # ③ 匹配推荐引擎
│   └── utils.py                # 通用工具
├── config/config.default.yaml  # 默认配置模板
├── data/                       # 干员数据 JSON（待添加）+ 抓取缓存
├── resources/templates/        # Web 前端模板
└── tests/
```

## 🗺️ 版本规划

| 版本 | 内容 |
|------|------|
| **v0 (MVP)** | 单视频输入 + Excel box + 评论区（置顶/高赞）映射命中推荐 |
| **v1** | 合集遍历、弹幕挖掘、LLM 补充推断、关键位风险分级与溯源 |
| **v2** | 森空岛扫码登录、长视频分段兼容、干员数据更新机制 |
