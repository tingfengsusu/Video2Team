## 正文

上次发帖之后收到不少反馈，攒了一波一起更到 **v0.3.0**。核心那件事没变——**把大佬的挂机作业，改成你能抄的版本**；这次补的主要是**打矢量突破这类活动**会遇到的那堆麻烦：一关关的补给关（游戏里叫「特别战线」）到底要打哪几个、谁得先打谁、打哪一关会把别的关要用的干员占掉——以前这些得自己在游戏里一格格对着数，现在插件替你算。

**【这次更新了什么】**

**1. 要打哪些补给关，插件自己认**

【此处插入 图1】**（补给关候选池：勾选一套后，别的关共用干员被置灰 + 标注占用来源）**

你把特别战线那一屏截进去（或粘贴），插件会按**序号**认关（顺序 = 从上到下、从左到右），而且会把它认的依据写出来——比如「特别战线网格第 5 格 → VEC-SP02，格内文字『催化装备』」。**认错了你一眼就能看出来**，底下还有「不是这关」可以把它去掉。

每一关都给你一份候选池（MAA 作业站 + B站 攻略视频，两条来源分开标），勾一套就等于"这关用这套"：

- 这套方案的干员会被登记成**占用**，其它关里用到同一个干员的方案会**灰掉 + 删除线 + 锁**，行尾还会写「⚠ 凯尔希 已被 VEC-SP02 占用——勾选本方案会把占用改到本关」，你可以点它把占用"抢"回来；
- 缺干员的方案默认藏起来（也可以点「点开查看」扫一眼）；
- 结果区会实时跟着变，不用重新分析。

**2. 补给关之间的先后顺序，它也替你记着**

有些补给关**要先打掉前置关才能开**（实测：SP10 要先打 SP09、SP12 要先打 SP11），而打前置关同样要占干员。所以现在只要识别到后置关，就会**自动把前置关也加进候选池**，并注明「关卡链：本关需要先打 VEC-SP09」——省得排完阵容才发现少算了一关。

**3. 新入口：「选择补给关…」**

【此处插入 图3】**（「选择补给关…」浮层：按序号点选 / 拖动连续选 / 取消识别错的关）**

候选池顶部这个按钮，打开是一个**按序号排的补给网格**，像游戏里那样点：**按住拖动可以连续选**，已经在池里的默认勾着（取消它 = 这关识别错了，应用后会从列表移除）。适合识别不准或漏关的时候手动挑。

**4. 大窗口结果页**

【此处插入 图4】**（大窗口结果页：左候选池、右阵容，勾选双向实时同步）**

点「⤢ 大窗口查看结果」会开一个独立窗口：**左栏前置关候选池、右栏本关阵容**，一屏看全，和视频页面板/扩展弹窗的勾选**双向实时同步**。视频页关掉，它也自己关。

**5. 一些顺手修的**

- 换视频/换分P 不再串上一个视频的结果；
- 结果按「视频 + 分P」缓存，可以「清除本页缓存」重来；
- 启动会读一下仓库里的公告（这次更新就是这么通知老用户的）；
- 发现新版会在面板顶部提示，附「复制升级步骤」。

**【它到底做什么】**

【此处插入 图2】**（结果总览：本关用这套 + 前置关各选了什么）**

一句话：**识别攻略视频的编队 → 把这关弹幕+评论里所有「XX 可以换 XX」挖出来 → 和你的练度表逐一比对 → 给你一份你能用的阵容。**

- **绿=你有、红=你没有**，扫一眼就知道哪些现在能抄；
- 缺的干员优先给**弹幕/评论里的实战替代**，每条都带原文和**溯源链接**（跳回原评论）——这工具只搬运社区经验，不发明建议；
- 关键位（UP 主强调的）单独标出，换它有风险；
- **黑话能看懂**：老玛/大姨/askl 这类 300 多条社区昵称能还原成全名；
- **异格能归一**：弹幕说「星熊」、阵容里只有「斩业星熊」，它知道是同一个；
- 不认识的称呼会记下来提醒你确认一次；
- **不需要 API Key**：默认走 DeepSeek 网页版，点一下自动填好提示词并读取结果，全程免费；有 API 的话也能直连（任意 OpenAI 兼容：DeepSeek／智谱／Kimi／本地 Ollama 都行）。

**【怎么用】**

1. 装插件（下载见下，Chrome/Edge 都行）
2. 设置里导入练度表：一图流「我的干员 → 导出为 Excel」直接上传（**本地解析，不上传**）
3. 打开攻略视频 → 暂停在编队画面 → 抓帧（或 Ctrl+V 粘贴截图）→ 分析

**【下载安装（v0.3.0）】**

- GitHub（推荐，附件里有已经打包好的 zip）：`https://github.com/tingfengsusu/Video2Team/releases`
- 打不开 GitHub 用蓝奏云：`<把新包传上去后替换这里>`

下载 zip → 解压 → `chrome://extensions` 打开开发者模式 → 「加载已解压的扩展程序」选中解压出来的文件夹。（Edge 是 `edge://extensions`，步骤一样）

**已经在用旧版的老哥怎么升级**：本机有 git+node 的话，在仓库目录跑 `npm run selfupdate`，然后回 `chrome://extensions` 点「刷新」、F5 一下开着的 B 站页面；没有环境就直接下新 zip 解压**覆盖**原来的文件夹，再点刷新。

免费开源，不碰你的账号：B站只读公开的弹幕和评论，练度表全程在本地解析、不上传。

**【最后】**

这插件是我自己活动期在用，哪里不顺手就改哪里。这次补给关这块改完，我自己打矢量突破顺手多了，就发出来给同样在打的人省点事。装不上、报错、或者觉得哪里还是别扭，回帖说一声，我看到就修；想加的功能也可以直接提。

## 发帖提示

- **封面**：用 `01-pool-occupied.png`（红绿 + 灰掉置灰的对比最有信息量）；备选 `04-big-window.png`。
- **图片顺序**：01 → 02 → 03 → 04，与正文标注一致；正文里我按"先讲新功能、再讲核心"的顺序排，你把图插到对应段落即可。
- **评论区自己置顶一条**：下载链接（GitHub + 蓝奏云）+ 「装完先在设置里导练度表，不然名字全是红的」这种一句话 FAQ；再加一条「升级只需要覆盖文件夹后点刷新，不用卸载重装」。
- **旧帖怎么处理（推荐做法）**：
  1. **只改旧帖首行**，加一句：`⚠️ 已更新到 v0.3.0（补给关自动识别 / 关卡链 / 大窗口），新帖：<新帖链接>`；
  2. 旧帖正文和评论区**不再维护**（蓝奏云老链接留着也行，反正第一条就指路了）；
  3. **不要**在新帖里写成"补丁帖"（"接上一帖"）——小黑盒的新读者很多是从搜索/推荐来的，新帖要能独立读懂。
- **要不要两帖互相链接**：只做"旧 → 新"的单向指路就够；新帖里加一句"上一帖的老哥直接看这帖就行"，不需要贴旧帖链接（旧帖内容是 v0.2.0 的，细节已经被这帖覆盖）。
- **二次曝光**：小黑盒对"编辑过的老帖"基本不给新曝光，想要再被刷到只能发新帖——这也是建议发新帖而不是只改旧帖的原因。
- 发完把帖子链接发我，常见提问（怎么用/报错/杀毒误报/练度表格式变了）我整理一份 FAQ，你贴到评论区置顶。
