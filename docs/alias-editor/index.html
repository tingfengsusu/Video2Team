1 · 导入与修正

从插件设置页导出错题本，再粘贴到这里；也可直接编辑仓库读取到的完整别名表。

2 · 清除歧义

红色行会列出冲突目标。把昵称改成更具体的写法，或让重复昵称统一指向同一名干员。

3 · 复制并提 PR

点「复制 JSON 并打开 GitHub 编辑页」，粘贴覆盖原 JSON，填写说明后提交 Pull Request。

导入错题本

支持插件「导出错题本」的 JSON、原始 corrections_pending 对象，或 {"昵称":"干员全名"} 对照对象。待确认条目会先进入表格，干员全名留空供你填写。
