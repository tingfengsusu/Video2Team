## 正文

事情是这样的。这次活动EX关，点开一个摆完挂机攻略，视频里八个干员我缺俩。按老流程走一遍：暂停看编队 → 记下缺谁 → 翻评论区，几十条「XX能替XX」，需要一个个找适合自己的……半小时过去了，作业还没开始抄。

烦了很多次之后，我干脆写了个浏览器插件，把这一套自动化了。

**【它长这样】**（插入图四：视频页 + 右缘浮动入口）

在攻略视频页右缘鼠标移过去会滑出一个「阵容适配」按钮，点开后不用离开视频页就能操作。

**【它做什么】**（插入图1：点击分析、提示词注入到 DeepSeek 网页版）

插件识别攻略视频的编队阵容，把这关弹幕+评论区里所有「XX可以换XX」的建议挖出来，和你导入的干员练度表逐一比对，给你一份「你能用的阵容」。（插入图2、图3：适配结果）

- ✓ 你有的 → 保留
- ⚠ 你缺的 → 自动匹配弹幕/评论里的替代建议，附原文和溯源链接
- ✗ 实在没有的 → 标红，提示回评论区确认
- 核心干员（UP主强调的关键位）单独标注：换关键位有风险，慎重抄

干员名字的颜色就是你有/没有：**绿色你有，红色你没有**——扫一眼就知道哪些建议现在就能抄。

**【几个我比较得意的点】**

- **黑话能看懂**：弹幕里的「老玛可以替askl」「大姨换杰哥」，能还原成玛恩纳/阿斯卡纶/娜仁图亚（收集了300多条社区昵称，还会随着游戏更新自动同步）
- **异格能归一**：弹幕说「星熊」，阵容里只有「斩业星熊」——它能理解说的是同一个
- **不需要API Key**：走DeepSeek网页版，点一下分析自动填好提示词、自动读取结果，全程免费
- **建议全部带来源**：每条替代都能点「溯源」跳回原评论，不是AI编的——这工具只搬运社区实战经验，不发明建议
- 有API的话也能直连（任意OpenAI兼容：DeepSeek/智谱/Kimi/本地Ollama都行）
- 遇到不认识的称呼会记录下来提醒你，确认一次它下次就认识了

**【怎么用】**（插入图5：设置页）

1. 装插件（下载链接在下面，Chrome/Edge都行）
2. 设置里导入练度表：去一图流「我的干员 → 导出为Excel」直接上传（本地解析，不上传）
3. 打开攻略视频 → 暂停在编队画面 → 抓取画面 → 分析
